# Complete Project Techniques, Inputs, and Outcomes Map

This document maps every project in the portfolio across three dimensions:

1. **Concrete techniques** actually used in the notebook.
2. **Inputs**: source, approximate volume, structure, and data type.
3. **Outcomes / conclusions**: stored metrics, findings, and the main lesson from the analysis.

Metrics below come from the outputs already stored in the migrated notebooks. The notebooks were **not re-executed** during the portfolio migration. For projects that fetch data at runtime, input volume can vary and is described accordingly.

## Cross-portfolio view

Across the 18 projects, the portfolio covers a progression from **data validation and descriptive analysis** through **statistical inference, feature selection, classical supervised models, hyperparameter tuning, unsupervised representation learning, and neural-network fundamentals**.

A useful way to read the portfolio is therefore not only by algorithm, but by the analytical question being answered:

- **Can the data be trusted?** — Diabetes EDA, biodiversity cleaning.
- **What relationships or patterns exist?** — GDP/life expectancy, NBA, biodiversity.
- **Which variables matter?** — Wrapper selection, Random Forest importance, L1 regularization.
- **How well can a target be predicted?** — Gradient Boosting, SVM, Random Forest, Naive Bayes, recommender systems, deep learning.
- **Can structure be discovered without labels?** — K-Means and PCA projects.
- **What are the limits of the model class?** — XOR perceptron, PCA-vs-original-feature comparison, class-specific recall in heart-failure prediction.
